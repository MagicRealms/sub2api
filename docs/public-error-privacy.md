# 客户侧错误隐私

本站由 `internal/util/errorprivacy` 统一生成面向客户的错误投影，站点标识为「太阳新世界（codex.magicrealms.top）」。

- API 网关在分组路由、账号保底和 Ops 记录之外包一层响应 writer。它只处理最终写给客户的错误；内部匹配、健康判断、重试、限流、保底、计费和管理员记录继续使用原始数据。
- 覆盖 HTTP 错误 JSON、HTTP 200 中的错误信封、SSE `error` / `response.failed`、Responses WebSocket、Live sideband、Grok 实时语音错误和 WebSocket 关闭原因。管理员的账号连通性测试也使用相同展示规则；后台自动测试和原始日志保留诊断。
- 已识别的上游错误使用固定本站文案，不回显供应商自由文本。超时、限流、模型不可用、上下文超限、会话续接失效和内容政策分别归类；上下文压缩与续接恢复需要的标准短语保留。
- 保留 HTTP 状态、协议事件类型、标准错误 `type` / `code` / `param` / `status`、关联 ID、`Retry-After` 和限流响应头。错误信封采用字段白名单，过滤 `provider`、`endpoint`、`details`、内部 URL、账号等额外元数据；含地址或凭证的伪装协议字段也被过滤。
- 清除网关响应中的内部诊断头；错误响应移除 `Location` / `WWW-Authenticate`。成功的重定向、图片和内容资源不受错误规则影响。
- 用户错误列表与详情在读取时脱敏，因此已有历史记录立即受保护，无需删除或改写管理员数据库记录。异步图片任务保留轮询字段，批量图片的供应商错误使用本站文案。
- 其他服务商的普通模型回复、正文链接、引用、图片结果和正常 SSE 增量保持原样。本地鉴权、参数与价格策略错误保留必要的可操作提示。

## ShareLLM 的定向身份隐藏（w04）

- 用户选择第 1–5 项：公开资源隐藏、对客别名、管理员目录、对客响应投影和保留错误脱敏。未选择提示词拦截，不增加请求拒绝规则。
- 公开内置平台目录中的该平台使用 `route_relay` /「路由中转」，不带真实基址。完整目录仅由 `/api/v1/admin/platform-catalog` 提供，沿用管理员鉴权；普通用户和匿名请求无权读取。管理员账号/分组/渠道表单加载真实目录后才使用供应商预设，登出与离开管理页面恢复公开目录。
- 网关及用户面板的最终响应边界定向替换该供应商名称、域名、JSON 字段和响应头，域名投影为 `codex.magicrealms.top`；用户可见平台投影为 `route_relay`。模型广场也在最终 JSON 序列化后投影，避免改变模型筛选、分组政策或本地化逻辑。后台账号凭据、数据库、供应商路由和原始 Ops 诊断保持原值。
- 用户平台筛选接受公开别名并还原为内部平台 ID 后执行原有权限校验；公开设置接口及首页注入配置也使用同一身份投影。管理员完整目录响应禁止共享缓存。
- SSE 与 WebSocket 对完整 JSON 进行结构化替换，保留事件类型和数字精度；公开名称拆成多个文本增量时，每连接最多记忆 32 个输出槽、每槽 32 字节后缀，在补全身份的增量中替换重叠部分，不延迟事件或缓存全文。
- 二进制音视频、图片下载不会做字节替换。此功能隐藏网关主动回显的供应商身份及常见明文回复，不承诺阻止模型根据公开知识猜测，也不处理任意编码、图像内容或人为暗号。

HTTP 错误和 SSE 单个事件最多保留 64 KiB；超过限制的错误/未知事件以通用错误代替，不把截断的原文返回客户。大的标准正常 SSE 事件在达到上限后继续直接传输；原传输层的事件/行/帧限制继续生效。writer 不创建后台 goroutine，结束后拒绝迟到写入，避免引用请求池对象。

请求定位优先使用响应中的 `X-Client-Request-ID` / `X-Request-ID`；管理员通过 Ops 查看相应的原始上游诊断。
